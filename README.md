# Layout Shifter

## Resumen

Ejercicio de maquetación adaptable con Flexbox. Los bloques cambian de ancho y de posición para componer una distribución distinta en cada tamaño de pantalla.

## Cómo verlo

Abre [index.html](index.html) y cambia el ancho de la ventana. En [styles.css](styles.css) puedes seguir las reglas de 600 y 800 píxeles y el uso de `order` en escritorio.

## English summary

A responsive Flexbox exercise that changes the width and position of content blocks to create different layouts at different screen sizes.
